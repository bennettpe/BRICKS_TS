Transaction server — static web server is live.

This page is served by the bricks static web server from webserver_dir (default runtime/web). Drop your own HTML/CSS/JS here and it is served as-is.

Around the server

  • 3270 terminal (web3270)
  • /metrics (JSON snapshot, when enabled)

Static frontend + transaction backend

When WAPI is enabled, this server's listener also serves your static files for any path that no transaction route matches (a CICS URIMAP USAGE(STATIC)-style document). Your page can then call EXEC CICS WEB transactions as its API: 

fetch('/api/customers')        // -> a TRANSID via web_routes.conf
  .then(r => r.json())
  .then(render);

Same origin, no CORS — the frontend and the transaction backend are both bricks.

Manage this server from CEDA WEBSERVER; watch its counters on CEMT MONITOR.
